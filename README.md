# Atlanta Food Finder Web Application
(Forked from [Original Repo](https://github.com/Connor5190/CS2340-Project-1.git))

## Overview

This project served to allow its users to search up restaurants in the Atlanta area and allow them to filter by distance and restaurant ratings. Additionally, all the restaurants would be displayed in an interactive google map using the google maps API, and users could also favorite specific restaurants. 

## My Role & Contributions

I was actively involved in:
- **Frontend Development**: Implemented the dashboard UI design using CSS flexbox and grid layouts.
- I was responsible for the **backend integration**, specifically implementing the **implementation of the Google Maps API's**. This included:

  - Designing and implementing the **user authentication system** to allow users to register an account with out application.
  - Utilized Google Maps Javascript API to implement an interactive google map in the dashboard webpage
  - Utilized Google Maps Places API to allow users to search for restaurants and filter their searches such that users could find restaurants catered to their desires
  - Implemented the backend logic flow allowing users to delete their account from the application
- **Feature Development**: Implemented the adaptive details page. This was a template page that, when a user clicked on a restaurant it route the user to this page and would fill the template with the restaurants details necessary for the user to know. Here the user could see reviews and ratings, and the user could make their own rating and review. 

## Technologies Used

- **Django** (Python web framework)
- **Google Maps Javascript API**
- **Google Maps Places API and Nearby Search API**
- **JavaScript & jQuery**
- **SQLite** for data storage during development
